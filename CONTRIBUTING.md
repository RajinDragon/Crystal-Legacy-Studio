# Contributing

Thank you for helping build Crystal Legacy Studio.

## Before starting

- Read `docs/PLUGIN_DEVELOPMENT.md`.
- Check `docs/KNOWN_ISSUES.md`.
- Prefer a new or improved plugin over adding editor-specific code to the shell.
- Discuss schema changes that affect shared project files before implementing them.

## Pull request expectations

A pull request should contain one focused feature or fix and include:

- a concise summary
- setup and reproduction steps
- files/resource groups affected
- screenshots for UI changes
- tests or a manual test checklist
- known limitations

Do not commit:

- game-owned copyrighted assets
- personal game installations or absolute local paths
- save files containing personal information
- API keys or signing keys
- Cheat Engine tables as runtime dependencies
- Python cache folders

Use `{UNTESTED}` in the plugin label for a plugin that has not been verified in game.
