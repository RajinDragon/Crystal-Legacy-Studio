# GitHub Upload Checklist

1. Choose and add a `LICENSE` file. No license is selected in this preview.
2. Create a clean repository and copy the contents of `Crystal Legacy Studio` into it.
3. Confirm `.gitignore` excludes caches, local settings, logs, builds and game data.
4. Do not upload Square Enix game assets or extracted MagiciteExport data.
5. Create a release ZIP from the repository contents or attach the supplied community-preview archive.
6. Add screenshots to the repository documentation without including personal paths where possible.
7. Enable Issues and add labels such as `plugin`, `bug`, `untested`, `sprite`, `monster`, and `help wanted`.
8. Pin `README.md`, `CONTRIBUTING.md`, and `docs/PLUGIN_DEVELOPMENT.md` in the project description/wiki as appropriate.
